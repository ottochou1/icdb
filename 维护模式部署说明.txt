华政选课：闭站维护开关补丁

基于用户上传的 icdb_MAcRx.tar.gz 制作。尚未部署到线上，默认关闭。

部署步骤
1. 备份服务器上即将覆盖的文件。
2. 将补丁内 icdb/ 下的文件上传到网站根目录，保留目录结构并覆盖对应文件。不要上传外层 icdb 目录形成重复层级。
3. 确认 PHP 进程可以在网站根目录创建和替换 maintenance-state.php。无需改数据库，无需运行 install.php 或 upgrade.php。勿使用 777；按主机商的站点目录权限配置。
4. 管理员登录后进入「管理后台 → 网站设置」，填写维护文案并保存。开启维护需要在页面内确认。
5. 用无痕窗口验证首页维护提示、api.php?r=courses.list 返回 HTTP 503；管理员窗口验证后台仍可使用。
6. 关闭开关并保存，无痕窗口刷新，确认恢复开放。首次发布若后台仍显示旧页面，请刷新浏览器及主机/CDN 缓存。

维护行为
- 默认没有状态文件，网站正常开放。
- 开启后，普通用户的页面与业务 API 被阻止访问；API 返回 MAINTENANCE 和 HTTP 503。
- 管理员可以继续使用网站和后台。维护期间仍开放登录、查询当前登录身份、退出与维护状态接口。
- 登录入口：网站地址/?admin=1#/login 。URL 只提供登录页面，不授予管理员权限；管理权限仍由后端账户校验。
- 已打开的页面不会主动抹去此前加载的内容，但下一次业务请求会在服务端被阻止。
- 静态 CSS/JS 等资源仍可访问。此功能不等同于停止 Web 服务。
- 维护文案最多 300 字，作为普通文本显示。

紧急恢复
若无法进入后台，使用主机文件管理器将根目录 maintenance-state.php 重命名为 maintenance-state.php.disabled，刷新即可恢复默认开放状态。保留文件以便排查。
若回滚代码，恢复先前备份的 5 个已有文件，并移除本次新增的 maintenance.php、maintenance-page.php 与生成的 maintenance-state.php。

文件清单
覆盖：index.php、api.php、assets/js/api.js、assets/js/app.js、assets/js/views/admin.js
新增：maintenance.php、maintenance-page.php
运行时生成：maintenance-state.php（未随补丁提供；内容带 PHP 退出保护，不应当作 PHP 配置 include 执行）
