# 华政选课

PHP 7.4+ / PDO MySQL 的课程评分与选课讨论社区，前端使用原生 JavaScript 模块。

## 部署

将项目部署到支持 PHP 和 MySQL 的站点，按照 `install.php` 安装流程配置数据库。已有网站升级时保留服务器上的 `config.php` 和 `install.lock`，不要重新安装。数据库结构参考 `schema.sql`。

真实数据库配置、学生认证上传材料和运行时状态不纳入版本控制。仓库只提供 `config.example.php`。

## 闭站维护

管理员进入「管理后台 → 网站设置」，可开启维护模式并编辑提示。开启后普通页面及业务 API 暂停访问，管理员仍可登录操作。默认关闭，无需数据库迁移。PHP 进程需要具备在项目根目录保存维护状态文件的权限。

维护期间管理员登录入口：`/?admin=1#/login`。

详细发布、恢复与验证步骤见 [维护模式部署说明](维护模式部署说明.txt)。维护功能已完成本地逻辑检查，仍需在实际服务器验证账号与写入权限；本项目尚未自动部署到线上。

原压缩包附带的演示账号及内容数据未纳入仓库；安装时请取消勾选「导入演示数据」，并设置自己的管理员账号。
